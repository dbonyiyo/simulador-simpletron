# Simpletron

Simulador de la computadora Simpletron escrito en C.

## Compilación y Ejecución
Para compilar el código fuente desde la terminal:
\`\`\`bash
gcc simpletron.c -o simpletron
\`\`\`

Para correr el programa:
\`\`\`bash
./simpletron
\`\`\`
